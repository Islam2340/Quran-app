# Коран — Android book app

Проект собран из файла «Копия Коран 19.05.26.docx». В книгу перенесены 114 сур.

## Функции
- содержание всех 114 сур;
- переход между сурами;
- продолжение с последней открытой суры;
- поиск по полному тексту;
- закладки;
- светлая/тёмная тема;
- увеличение/уменьшение шрифта;
- кнопка «Поделиться»;
- работа полностью офлайн;
- иконка приложения из предоставленного изображения.

## Сборка APK
Откройте папку в Android Studio и выполните Build → Generate App Bundle / APK → Generate APK.
Требуется Android SDK 35 и Gradle/Android Gradle Plugin, Android Studio установит необходимые компоненты.
